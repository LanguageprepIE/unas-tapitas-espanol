# Migración del prototipo original

Este paquete reúne el código original bajo una raíz compatible con GitHub Pages.

- Las rutas de los dos archivos de listening apuntan a `assets/audio/`.
- Los MP3 incluidos son copias byte a byte del ZIP original. En el repositorio ya existen los mismos audios, por lo que deben conservarse sin regenerar.
- No se han cambiado las actividades de Learn, Practise y Communicate.
- Explore sigue en su versión original; el rediseño de seis laboratorios está pendiente de integrar.
- Ejecuta `npm test` para verificar la lógica original.
- Para desplegar GitHub Pages, selecciona la rama main y la carpeta / (root).
